# US-005 — Listar drones do usuário autenticado

## O que foi pedido

Usuário autenticado lista todos os seus próprios drones cadastrados; drones
de outros usuários nunca aparecem no resultado (RF-002.3, RN11).

## Passo a passo do que foi implementado

- `src/modules/drone/drone.service.ts` — `droneService.listar(usuarioId)`:
  `prisma.drone.findMany({ where: { userId: usuarioId } })`. Sem paginação
  ou ordenação customizada (fora de escopo, conforme US-005).
- `src/modules/drone/drone.controller.ts` — `listar`: chama o service com
  `req.usuarioId` e responde `200` com o array (vazio ou não).
- `src/modules/drone/drone.routes.ts` — `GET /` registrado, reaproveitando o
  `autenticacaoMiddleware` já aplicado a todo o router (US-004).

## Alternativas de implementação consideradas

- Nenhuma alternativa relevante avaliada — a listagem é direta e o
  isolamento por usuário já é garantido pelo filtro `where: { userId }`, o
  mesmo padrão que será reaproveitado nas checagens de ownership de US-006 a
  US-008.

## Como foi testado

Plano de testes: `docs/tests/US-005-plano.md` (5 casos). Todos cobertos em:

- `src/modules/drone/drone.controller.spec.ts` (e2e): caso feliz (lista com
  2 drones), lista vazia, isolamento entre usuários (drones de `outro` não
  aparecem para `hugo`), volume (5 drones do mesmo usuário) e ausência de
  token.
- `src/modules/drone/drone.service.spec.ts` (unitário): confirma o filtro
  por `userId` e o caso de lista vazia diretamente no service.

Suíte rodada com `pnpm test`: 7 suítes, 59 testes, todos passando (nenhuma
regressão em Sprint 01 + US-004).
