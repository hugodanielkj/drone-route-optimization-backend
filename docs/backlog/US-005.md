# US-005 — Listar drones do usuário autenticado

**Como** usuário autenticado,
**quero** listar todos os meus drones cadastrados,
**para** ver quais tenho disponíveis para uso em cálculos de rota.

## Requisito de origem

RF-002.3

## Critérios de aceite

- **Given** um usuário com drones cadastrados, **when** ele solicita a listagem,
  **then** o sistema retorna todos os drones pertencentes a ele.
- **Given** um usuário sem nenhum drone cadastrado, **when** ele solicita a
  listagem, **then** o sistema retorna uma lista vazia.
- **Given** drones cadastrados por outros usuários, **when** a listagem é
  solicitada, **then** esses drones não aparecem no resultado.

## Fora de escopo

- Filtros, paginação ou ordenação customizada.
- Cadastro, consulta individual, edição e exclusão (US-004, US-006 a US-008).
