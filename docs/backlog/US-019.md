# US-019 — Listar missões do usuário autenticado

**Como** usuário autenticado,
**quero** listar todas as minhas missões calculadas,
**para** ter uma visão geral de quais pares (drone, mapa) já têm rota calculada.

## Requisito de origem

RF-004.12

## Critérios de aceite

- **Given** um usuário com missões persistidas, **when** ele solicita a listagem,
  **then** o sistema retorna todas as missões pertencentes a ele (ativas e
  desativadas), incluindo drone, mapa e status de cada uma.
- **Given** um usuário sem nenhuma missão persistida, **when** ele solicita a
  listagem, **then** o sistema retorna uma lista vazia.
- **Given** missões pertencentes a outros usuários, **when** a listagem é
  solicitada, **then** essas missões não aparecem no resultado.

## Fora de escopo

- Filtros por status, paginação ou ordenação customizada.
- Consulta de detalhe de uma missão específica (US-020).
