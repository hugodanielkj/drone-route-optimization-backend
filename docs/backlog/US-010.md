# US-010 — Listar mapas do usuário autenticado

**Como** usuário autenticado,
**quero** listar todos os meus mapas cadastrados,
**para** ver quais áreas de operação tenho disponíveis para cálculo de rota.

## Requisito de origem

RF-003.3

## Critérios de aceite

- **Given** um usuário com mapas cadastrados, **when** ele solicita a listagem,
  **then** o sistema retorna todos os mapas pertencentes a ele.
- **Given** um usuário sem nenhum mapa cadastrado, **when** ele solicita a
  listagem, **then** o sistema retorna uma lista vazia.
- **Given** mapas cadastrados por outros usuários, **when** a listagem é
  solicitada, **then** esses mapas não aparecem no resultado.

## Fora de escopo

- Filtros, paginação ou ordenação customizada.
- Cadastro, consulta individual e demais operações (US-009, US-011 a US-015).
