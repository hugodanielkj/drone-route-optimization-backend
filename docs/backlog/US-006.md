# US-006 — Consultar drone por id

**Como** usuário autenticado,
**quero** consultar os detalhes de um drone específico meu,
**para** conferir seus atributos antes de usá-lo em um cálculo.

## Requisito de origem

RF-002.4 (RN11)

## Critérios de aceite

- **Given** um drone pertencente ao usuário autenticado, **when** ele é consultado
  pelo id, **then** o sistema retorna seus atributos completos.
- **Given** um id de drone que não existe, **when** ele é consultado, **then** o
  sistema retorna não encontrado.
- **Given** um id de drone que pertence a outro usuário, **when** ele é consultado
  pelo usuário autenticado, **then** o sistema retorna não encontrado (não revela
  que o recurso existe para outro dono).

## Fora de escopo

- Listagem (US-005), edição (US-007), exclusão (US-008).
