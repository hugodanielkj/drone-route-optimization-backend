# US-020 — Consultar detalhe de uma missão

**Como** usuário autenticado,
**quero** consultar o detalhe completo de uma missão minha,
**para** ver todas as pernas de rota (sequência de pontos e consumo) e o consumo
energético total.

## Requisito de origem

RF-004.13 (RN11)

## Critérios de aceite

- **Given** uma missão pertencente ao usuário autenticado, **when** ela é
  consultada pelo id, **then** o sistema retorna todas as pernas de rota (sequência
  ordenada de coordenadas e consumo de cada uma), o consumo energético total e o
  status.
- **Given** um id de missão que não existe, **when** ela é consultada, **then** o
  sistema retorna não encontrado.
- **Given** uma missão que pertence a outro usuário, **when** ela é consultada
  pelo usuário autenticado, **then** o sistema retorna não encontrado.

## Fora de escopo

- Listagem (US-019).
- Disparo de novo cálculo — isso acontece via US-016/US-017/US-018, não nesta
  consulta.
