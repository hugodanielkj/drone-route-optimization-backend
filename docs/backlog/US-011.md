# US-011 — Consultar mapa por id

**Como** usuário autenticado,
**quero** consultar os detalhes de um mapa específico meu,
**para** conferir seu ponto de carregamento e pontos de irrigação antes de usá-lo
em um cálculo.

## Requisito de origem

RF-003.4 (RN11)

## Critérios de aceite

- **Given** um mapa pertencente ao usuário autenticado, **when** ele é consultado
  pelo id, **then** o sistema retorna o ponto de carregamento e todos os pontos de
  irrigação.
- **Given** um id de mapa que não existe, **when** ele é consultado, **then** o
  sistema retorna não encontrado.
- **Given** um id de mapa que pertence a outro usuário, **when** ele é consultado
  pelo usuário autenticado, **then** o sistema retorna não encontrado.

## Fora de escopo

- Listagem (US-010), alteração de pontos (US-012 a US-014), exclusão (US-015).
