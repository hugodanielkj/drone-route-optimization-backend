# US-007 — Editar drone

**Como** usuário autenticado,
**quero** editar os atributos de um drone meu,
**para** corrigir ou atualizar suas características físicas.

## Requisito de origem

RF-002.5, RF-002.6 (RN02, RN13)

## Critérios de aceite

- **Given** um drone pertencente ao usuário autenticado, **when** ele edita nome,
  consumo por irrigação, velocidade média ou capacidade de bateria com valores
  válidos, **then** o sistema atualiza o drone.
- **Given** uma edição com algum atributo numérico zero ou negativo, **when** a
  edição é solicitada, **then** o sistema rejeita a requisição por falha de
  validação. (RN02)
- **Given** um drone que pertence a outro usuário, **when** a edição é solicitada
  pelo usuário autenticado, **then** o sistema recusa (não encontrado).
- **Given** um drone referenciado por uma ou mais Missões (ativas), **when** ele é
  editado com sucesso, **then** todas essas Missões passam para o status
  desativada. (RN13) — critério validável de ponta a ponta somente após US-016
  (cálculo de missão) existir; até lá, cobre-se com teste de integração
  simulando o relacionamento.

## Fora de escopo

- Cadastro (US-004), listagem (US-005), consulta (US-006), exclusão (US-008).
- Recalcular a Missão desativada — isso só acontece quando o usuário solicitar
  novo cálculo (US-018).
