# RF-003 — Gestão de Mapas

## Contexto e objetivo

O Mapa é o agregado raiz que representa uma área de operação: um único ponto de
carregamento e uma lista de pontos de irrigação. É o "dono" de suas coordenadas —
nenhuma coordenada existe ou é modificada fora do contexto de um Mapa específico
(RN08). Esta funcionalidade cobre o CRUD de Mapas e a manipulação encapsulada de
seus pontos.

**Ator envolvido:** Usuário autenticado (RF-001), dono dos seus próprios Mapas.

## Requisitos funcionais

- **RF-003.1** — O sistema deve permitir criar um Mapa informando um ponto de
  carregamento (coordenada x, y) e uma lista de um ou mais pontos de irrigação
  (coordenadas x, y), associado ao usuário autenticado. (RN01)
- **RF-003.2** — A criação de um Mapa deve ser recusada se a lista de pontos de
  irrigação vier vazia. (RN01)
- **RF-003.3** — O sistema deve permitir listar todos os Mapas pertencentes ao
  usuário autenticado.
- **RF-003.4** — O sistema deve permitir consultar um Mapa específico pelo seu
  identificador, desde que pertença ao usuário autenticado, incluindo seu ponto de
  carregamento e todos os pontos de irrigação. (RN11)
- **RF-003.5** — O sistema deve permitir alterar o ponto de carregamento de um
  Mapa existente, desde que pertença ao usuário autenticado. Essa alteração é uma
  operação do próprio Mapa — não existe endpoint que manipule uma coordenada
  isoladamente. (RN08)
- **RF-003.6** — O sistema deve permitir adicionar um ponto de irrigação a um Mapa
  existente, desde que pertença ao usuário autenticado. (RN08)
- **RF-003.7** — O sistema deve permitir remover um ponto de irrigação de um Mapa
  existente, desde que pertença ao usuário autenticado. (RN08)
- **RF-003.8** — A remoção de um ponto de irrigação deve ser recusada se ele for o
  último ponto de irrigação do Mapa — a lista nunca pode ficar vazia. (RN01)
- **RF-003.9** — Qualquer alteração no Mapa (ponto de carregamento, adição ou
  remoção de ponto de irrigação) desativa toda Missão que o referencie. (RN13)
- **RF-003.10** — O sistema deve permitir excluir um Mapa, desde que pertença ao
  usuário autenticado.
- **RF-003.11** — A exclusão de um Mapa deve ser recusada se existir qualquer
  Missão (ativa ou desativada) que o referencie. (RN15)
- **RF-003.12** — O cadastro de um Mapa deve ser recusado se a lista de pontos de
  irrigação tiver mais de 1000 pontos. (RN16)
- **RF-003.13** — O cadastro de um Mapa deve ser recusado se algum ponto de
  irrigação tiver a mesma coordenada do ponto de carregamento. (RN17)
- **RF-003.14** — O cadastro de um Mapa deve ser recusado se dois pontos de
  irrigação tiverem coordenadas iguais entre si. (RN18)
- **RF-003.15** — A alteração do ponto de carregamento (RF-003.5) deve ser
  recusada se a nova coordenada coincidir com algum ponto de irrigação já
  cadastrado no Mapa. (RN17)
- **RF-003.16** — A adição de um ponto de irrigação (RF-003.6) deve ser
  recusada se a coordenada coincidir com o ponto de carregamento do Mapa
  (RN17), com outro ponto de irrigação já cadastrado (RN18), ou se o Mapa já
  tiver 1000 pontos de irrigação (RN16).

## Requisitos não funcionais

- **RNF-003.1 (Validação)** — Toda entrada de criação/edição de Mapa e de seus
  pontos deve ser validada via DTO antes de chegar à lógica de negócio.
- **RNF-003.2 (Autorização)** — Toda operação de leitura, edição ou exclusão deve
  verificar que o Mapa pertence ao usuário autenticado antes de executar.
- **RNF-003.3 (Encapsulamento)** — Não deve existir nenhuma rota, tabela ou
  endpoint que trate uma Coordenada isoladamente, fora do contexto de um Mapa. Toda
  manipulação de coordenada passa por uma operação do Mapa. (RN08)

## Restrições e premissas assumidas

- As coordenadas (x, y) representam posições no plano em metros — unidade
  consistente com `average_speed` em m/s usado na fórmula de consumo (RF-004).
- Um Mapa possui exatamente um ponto de carregamento durante toda sua vida — não
  há operação de "adicionar" ou "remover" o ponto de carregamento, apenas de
  alterá-lo (ele sempre existe).
- Há um limite de 1000 pontos de irrigação por Mapa (RN16); não há limite de
  Mapas por usuário.
